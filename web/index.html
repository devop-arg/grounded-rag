How it is evaluated

Hybrid search fuses the lexical (BM25) and vector rankings and returns eight documentation pages. If the top similarity is below the calibrated threshold, the server abstains instead of guessing. Otherwise the model answers from those passages only. Every citation is checked against the passage text on the server, and a sentence without a valid citation is dropped.

Metrics are unavailable.

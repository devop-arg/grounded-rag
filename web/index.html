How it works

One real question, step by step: from the Spanish question to the verified citations.

  1. 1

    The question

    A question in Spanish arrives from the page and is answered in Spanish.

    ¿Qué diferencia hay entre VACUUM y VACUUM FULL?

  2. 2

    Translation for the lexical search only

    The English wording feeds the full-text index; the vector search and the prompt keep the original question, so the answer comes back in Spanish.

    difference between VACUUM and VACUUM FULL

  3. 3

    Hybrid search

    Full-text and embeddings rank the manual on their own, and weighted reciprocal rank fusion merges both lists into one.

    BM25 20 · cosine 20 · RRF 1

  4. 4

    Eight pages of the manual

    The eight best pages of the PostgreSQL 17 manual are sent to the model, never two slots for the same page.

    PostgreSQL 17 · 8 pages

  5. 5

    The model writes sentences with quotes

    Every sentence must carry a verbatim quote from the page it cites, numbered like the sources.

    VACUUM FULL reescribe la tabla en un archivo nuevo. [1]

  6. 6

    The server verifies every quote

    Each quote is checked against the passage text; a sentence whose quote is not there is dropped before anyone sees it.

    VACUUM FULL no necesita espacio extra en disco. [1] quote not found: dropped

  7. 7

    Answer or abstention

    What survives becomes the answer with its numbered citations and page links. If nothing survives, the server abstains instead of guessing.

    [1] [2] · abstain

The animation is decoration: with reduced motion every step is shown at once.

Why RAG and not a search engine?

A search engine returns links and leaves the reading to you. This assistant returns a sentence you can check.

  • It answers from one authorised, versioned source: the PostgreSQL 17 documentation, with no other versions and no blogs mixed in.
  • Every statement carries its verbatim quote and the link to the page, so it can be verified in one click.
  • It abstains when the documentation does not cover the question, instead of inventing an answer.
  • It works over private or internal documentation that a public search engine never indexes.
  • It synthesises several pages into a single answer instead of handing back a list of links.
  • The quality is measured on a public set: the exact figures are in the evaluation panel below and in the repository.

Measured on a public evaluation set. Evaluation in the repository

How it is evaluated

Hybrid search fuses the lexical (BM25) and vector rankings and returns eight documentation pages. If the top similarity is below the calibrated threshold, the server abstains instead of guessing. Otherwise the model answers from those passages only. Every citation is checked against the passage text on the server, and a sentence without a valid citation is dropped.

Metrics are unavailable.
